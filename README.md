# Klassetur 2027

Interaktivt kart over kandidatene til klasseturen for 10. trinn ved Kautokeino skole, juni 2027.

- `docs/index.html` er nettsiden (GitHub Pages publiserer fra `docs/`).
- `Klassetur-kart-2027.html` er den samme fila, til lokal bruk.
- `underlag/` inneholder turarkene, oversiktsarket og `lag_kart.py`, som bygger kartet fra arkene: `cd underlag && python lag_kart.py`.
